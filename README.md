## Tech Stack & Architecture

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS with custom glassmorphism design system
- **Motion & Graphics:** WebGL2 Fluid Lines, Three.js Constellations, Framer Motion, React Bits Pro Concave 3D Carousel
- **Typography:** Plus Jakarta Sans & JetBrains Mono

## Getting Started

### Prerequisites

- Node.js 18.18+ or 20+
- npm / yarn / pnpm

### Installation

```bash
git clone https://github.com/ACE-Society-IT/AES-Summit.git
cd AES-Summit
npm install
```

### Local Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
